# ⚡EnergyMon
IoT based real-time energy monitoring and control dashboard using Tuya Smart Plug. The Custom Personal Web-based live Dashboard is built using HTML, CSS, and Python.
The dashboard website is hosted in pythonanywhere.com platform.
